# 📐KiCad PCB Design Projects

A collection of PCB designs created using **KiCad**, covering schematic design, PCB layout, footprint integration, and 3D visualization.

## 🛠️ Tools 

**KiCad**

## 🔗 Boardrepo 

PCB designs are also uploaded to **Boardrepo** for easy viewing without downloading or installing KiCad.

View my Boardrepo profile: https://boardrepo.com/shruti-dorge18

Each project in this repository includes its corresponding **Boardrepo link** for viewing the PCB design.

## 📋 Repository Contents 

Each project may include:

* `.kicad_sch` — Schematic
* `.kicad_pcb` — PCB layout
* `.kicad_pro` — KiCad project file
* Images — Schematic, PCB layout, and 3D views
* Footprints
